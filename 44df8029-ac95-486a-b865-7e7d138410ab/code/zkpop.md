RequestProject/ZkPoPNary.lean — the n-ary operations witnessed in zero knowledge. The Σ-protocol is lifted from a scalar secret to an n-ary one: the public value is the linear form linComb g x = ∑ i, x i * g i, which with all-ones coefficients is exactly the reduction of the project's naryAdd (linComb_ones_cast), so a cell of the n-dimensional addition table is the secret. Proved: completeness (completeness_nary), special soundness with an extractor returning the whole tuple (extractVec, extract_nary, special_soundness_nary), and honest-verifier zero knowledge (simulate_eq_proveN, zeroKnowledge_nary_image). Every splitting of k into M parts is a witness (splits_witness, splits_completeness); two accepting transcripts extract a tuple summing to k (splits_soundness); the statement has Nat.multichoose M k witnesses (card_witnesses) and the transcripts hide which one is used (witness_indistinguishable). Refinement carries a witness to higher arity for the same public value (refine_witness), and each node of a splitting tree is a witness for its own value, so a tree proof is assembled node by node (tree_node_witness, tree_node_completeness).

RequestProject/ZkPoPProofs.lean — an argument of knowledge of a Lean proof. A Claim is a decidable checker; a Lean proof of Claim.Provable and a certificate accepted by the checker are the same data. Committing a certificate gives: completeness (proof_completeness), an extractor that outputs the certificate itself, which the checker again accepts (extract_proof, extract_certifies), and simulability of the verifier's view (proof_zero_knowledge). Tuples are packed into single certificates by base-(B+1) digits with an exact unpacking theorem (digitVec, encodeVec, digitVec_encodeVec, encodeVec_lt), turning the n-ary statement into a claim whose extracted certificate decodes to a genuine table cell (narySplitClaim, narySplitClaim_provable, narySplit_extract); factorClaim 7920 is the same construction over the order of M₁₁. Finally the layer is a fixed point: "I know an accepting transcript pair for (g, y)" is provable exactly when the secret behind y exists (transcriptPair_iff, proof_of_proof_idempotent), which yields a self-hosting proof tower — each level publishing the commitment of the certificate used below — provable at every level (towerClaim_provable, tower_commits_previous_proof).

RequestProject/ZkPoPSelfHosting.lean — the ZK layer inside the self-hosting economy. A round of the M-ary protocol carries M+2 base elements, costing rounds·(2M+5) under the flat tariff (zkCost_flat); proving beats enumerating, since the fibre of the table grows without bound (card_splits_ge_succ, enumeration_unbounded, zk_cheaper_than_enumeration). Re-proving the whole twelve-base catalogue at 128-bit soundness costs 1170 rounds per epoch (zkUpkeep_eq); a network whose yield covers that reaches the self-hosting stage (zk_network_self_hosts) while one that does not collapses (zk_network_collapses); and the verification bill of a tower of any depth is eventually affordable (tower_bill_affordable, selfhosting_tower_affordable, zk_self_hosting_closure).
